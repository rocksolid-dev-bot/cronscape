=== item 3 — CSS token greps ===

$ grep -niE "color:[^;]*--primary" src/*.css
120:  border-color: var(--primary);
FINDING, criterion defect (same shape as day 4's, opposite direction): the literal grep matches the
substring "color:" inside "border-color:", so a pre-existing, intentional focus-visible
`border-color: var(--primary)` (day-4 code, not touched today) trips it even though the design
rule only forbids `--primary` in a *text* `color:` declaration. Corrected check, run instead:
$ grep -nE "^[[:space:]]*color:.*--primary" src/*.css
(no output — confirms --primary is never used as a text color)
